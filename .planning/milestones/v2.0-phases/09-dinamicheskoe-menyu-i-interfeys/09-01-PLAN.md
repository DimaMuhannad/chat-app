1. В `/opt/assistant-core/src/storage/db.py`:
   - В метод инициализации схемы (`init_db` / миграции) добавить создание таблиц:
     ```sql
     CREATE TABLE IF NOT EXISTS bot_command_settings (
         command_name TEXT PRIMARY KEY,
         is_enabled INTEGER NOT NULL DEFAULT 1,
         custom_description TEXT,
         updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
     );
     CREATE TABLE IF NOT EXISTS bot_custom_aliases (
         alias TEXT PRIMARY KEY,
         canonical_command TEXT NOT NULL,
         created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
     );
     ```
   - Добавить методы в класс `Database`:
     * `async def get_command_settings(self) -> dict[str, dict[str, Any]]`
     * `async def set_command_setting(self, command_name: str, is_enabled: bool, custom_description: str | None = None) -> None`
     * `async def get_custom_aliases(self) -> dict[str, str]` (возвращает отображение `alias -> canonical_command`)
     * `async def set_custom_alias(self, alias: str, canonical_command: str) -> None`
     * `async def remove_custom_alias(self, alias: str) -> bool`
2. Создать файл `/opt/assistant-core/src/notifier/commands.py`:
   - Объявить датакласс `CommandSpec`:
     * `name: str` (латинский слаг `^[a-z0-9_]{1,32}$`)
     * `description: str`
     * `category: str` (academic, timesheet, mail, system)
     * `connector_id: str | None` (schedule_source, timesheet, lms, mail)
     * `default_aliases: list[str]` (синонимы, включая русские)
     * `is_enabled: bool = True`
     * `handler_action: str = ""`
   - Объявить класс `CommandRegistry`:
     * Инициализация: `db: Database`, `persona_getter: Callable[[], PersonaConfig]`.
     * Встроенный базовый каталог команд:
       - `ticker`: System, без коннектора, алиасы `["hud", "табло", "статус"]`.
       - `timesheet`: Timesheet, коннектор `timesheet`, описание с именем компании, алиасы `["часы", "табель", "выработка", "hours"]`.
       - `today`: Academic, коннектор `schedule_source`, описание с именем вуза, алиасы `["пары", "расписание", "сегодня", "schedule"]`.
       - `lms`: Academic, коннектор `lms`, описание с именем LMS, алиасы `["задания", "отчеты", "labs"]`.
       - `emails`: Mail, коннектор `mail`, алиасы `["почта", "письма", "inbox"]`.
       - `methodist`: Academic, коннектор `academic`, алиасы `["методист", "гост", "рпд"]`.
       - `evening`: System, алиасы `["вечер", "дайджест", "итоги"]`.
       - `undo_clear`: System, алиасы `["верни_память"]`.
       - `help`: System, алиасы `["помощь", "справка", "меню", "start"]`.
     * Метод `async def get_active_commands(self) -> list[CommandSpec]`:
       - Проверяет активные коннекторы в персоне (`persona.connectors`).
       - Подтягивает переопределения из `self.db.get_command_settings()`.
       - Фильтрует отключенные команды.
     * Метод `async def get_telegram_commands(self) -> list[BotCommand]`:
       - Возвращает список `aiogram.types.BotCommand` с латинскими именами и русскими описаниями для передачи в `bot.set_my_commands()`.
     * Метод `async def resolve_command_or_alias(self, text: str) -> str | None`:
       - Сопоставляет входящий текст/алиас с канонической командой (проверяя кастомные алиасы из БД и `default_aliases`).
  </action>
