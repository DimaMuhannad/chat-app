  </read_first>
  <action>
1. В `/opt/assistant-core/src/core/exceptions.py` определить исключение:
   `class MissingScopeError(PermissionError): pass`
   и сделать его доступным для импорта из `src.core.exceptions`.
2. В `/opt/assistant-core/src/core/ports/connectors.py`:
   - Убедиться, что в интерфейсах портов объявлены `required_scopes: ClassVar[tuple[str, ...]]`:
     * `BaseTimesheetProvider.required_scopes = ("timesheet.read", "timesheet.write")`
     * `BaseScheduleProvider.required_scopes = ("schedule.read",)`
     * `BaseCalendarSink.required_scopes = ("calendar.read", "calendar.write")`
     * `BaseLMSProvider.required_scopes = ("lms.read", "lms.write")` (per D-09).
3. В реализациях коннекторов:
   - В `/opt/assistant-core/src/connectors/aadhk/provider.py`: объявить `required_scopes: ClassVar[tuple[str, ...]] = ("timesheet.read", "timesheet.write")`.
   - В `/opt/assistant-core/src/connectors/guap_lms/client.py`: объявить `required_scopes: ClassVar[tuple[str, ...]] = ("lms.read", "lms.write")`.
4. В `/opt/assistant-core/src/composition.py`:
   - Импортировать `MissingScopeError` из `src.core.exceptions` и `has_binding`, `binding` из `src.persona.bindings`.
   - В фабриках коннекторов (`default_timesheet_service`, `default_lms_client` и др.):
     * Проверять наличие привязки: `if not has_binding(role): return None` (per D-11).
     * Получать привязку: `bound = binding(role)`.
     * Проверять разрешения: `req = set(provider_cls.required_scopes); actual = set(bound.scopes)`.
     * Если `not req.issubset(actual)`: выбрасывать `raise MissingScopeError(f"Коннектор {role} требует scopes {req}, у персоны только {actual}")` (per D-10).
5. Обновить `/opt/assistant-core/tests/test_ports_conformance.py`:
   - Добавить проверку наличия `required_scopes` на всех классах провайдеров.
   - Проверить возбуждение `MissingScopeError` при неполных scopes в привязке персоны.
   - Проверить возврат `None` при отсутствии привязки коннектора.
  </action>
  <acceptance_criteria>
    - `MissingScopeError` объявлен и выбрасывается при нехватке scopes.

    - Фабрика возвращает `None` для ролей без привязки.
    - `/opt/assistant-core/.venv/bin/pytest /opt/assistant-core/tests/test_ports_conformance.py -q` проходит успешно.
  </acceptance_criteria>
