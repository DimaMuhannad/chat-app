## 1. Транспорт и синхронизация Git по SSH

| Option | Description | Selected |
|--------|-------------|:---:|
| Локальные + SSH fetch | Читать локальные репозитории рабочих пространств, а при наличии SSH alias выполнять неблокирующий git fetch с таймаутом (20-30 с) | ✓ |
| Только оффлайн | Работать строго оффлайн по локальным коммитам в рабочих пространствах без автоматического git fetch | |
| Bare-зеркала в кэше | Клонировать репозитории во временные bare-зеркала в отдельной директории кэша | |

**Политика обработки сбоев SSH:**
| Option | Description | Selected |
|--------|-------------|:---:|
| Мягкий пропуск | Мягкий пропуск с фиксацией статуса ошибки (демон продолжает работу, в статусе репозитория фиксируется ошибка связи) | ✓ |
| До 3 повторов | Повторять попытку подключения до 3 раз с задержкой перед фиксацией недоступности | |

## 2. Аналитика коммитов и оценка прогресса

| Option | Description | Selected |
|--------|-------------|:---:|
| С момента последней синхронизации | С момента последней успешной синхронизации с Notion (с окном по умолчанию в 7 дней для первой синхронизации) | ✓ |
| Фиксированное окно 7 дней | Фиксированное скользящее окно за последние 7 дней при каждом цикле анализа | |
| Суточный срез (24 ч) | Только за последние 24 часа | |

**Формат резюме для public/internal:**
| Option | Description | Selected |
|--------|-------------|:---:|
| Семантическая сводка | Семантическая сводка на русском: ключевые изменения, статистика активности и флаг застоя (если нет коммитов > 7 дней) | ✓ |
| Дайджест по типам | Структурированный дайджест по типам (feat/fix/refactor/docs) с перечислением коммитов и анализом темпа | |
| Сухая статистика | Исключительно числовая статистика (кол-во коммитов, авторы, даты) без обращения к LLM | |
