## 1. Архитектура реестра команд (Dynamic Bot Menu)

| Option | Description | Selected |
|--------|-------------|:---:|
| Модульный CommandRegistry | Динамическое формирование команд на базе активных коннекторов персоны и SQLite переопределений с синхронизацией через `bot.set_my_commands()` | ✓ |
| Статический список в коде | Захардкоженный список `BotCommand` в `bot_handler.py` (текущее состояние) | |
| Полный отказ от Telegram Menu | Управление исключительно текстом или инлайн-кнопками без системного меню команд | |

**Выбор пользователя:** Модульный `CommandRegistry`, привязанный к коннекторам и настройкам персоны. При подключении/отключении сервисов меню адаптируется автоматически.

---

## 2. Управление алиасами и русскоязычными псевдонимами

| Option | Description | Selected |
|--------|-------------|:---:|
| Гибридное (БД + диалог) | Настройки и алиасы хранятся в SQLite, пользователь может переименовывать и скрывать команды прямо в диалоге бота («переименуй /timesheet в /часы») | ✓ |
| Только файл конфигурации | Алиасы настраиваются исключительно через ручное редактирование `persona.yaml` | |
| Жестко зашитые синонимы | Расширенный список регулярных выражений в коде `bot_handler.py` без возможности настройки пользователем | |

**Выбор пользователя:** Гибридное управление (хранение в SQLite с возможностью настройки как через конфигурацию, так и голосовыми/текстовыми командами в чате).

---

## 3. Контекстный интерфейс (Context-First UI & Quick Replies)

| Option | Description | Selected |
|--------|-------------|:---:|
| Временная Reply-клавиатура | Адаптивные Reply-кнопки по времени суток (Утро, День, Вечер) с возможностью скрыть/показать клавиатуру в 1 клик | ✓ |
| Постоянная статическая клавиатура | Фиксированный набор кнопок без учета времени суток | |
| Только Inline-кнопки под сообщениями | Отказ от Reply-клавиатуры в пользу инлайн-кнопок под каждым сообщением | |

**Выбор пользователя:** Адаптивная Reply-клавиатура с ротацией по времени суток (MSK) и кнопкой скрытия для поддержания чистоты экрана.

---

## 4. Аудит производительности и эргономики

| Option | Description | Selected |
|--------|-------------|:---:|
| Edge Caching + Feedback buttons | Кэширование быстрых ответов (< 250 мс для табеля и расписания), инлайн-кнопки оценки (👍/👎) под ответами секретаря и проактивные алерты коннекторов | ✓ |
| Прямые сетевые запросы без кэша | Каждый запрос расписания или табеля идет напрямую к источнику данных | |

**Выбор пользователя:** Edge Caching для мгновенного отклика (< 250 мс) и сбор телеметрии качества через инлайн-реакции.
