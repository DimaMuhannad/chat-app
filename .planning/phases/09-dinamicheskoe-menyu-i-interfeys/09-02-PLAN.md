1. В `/opt/assistant-core/src/notifier/bot_handler.py`:
   - В `handle_user_text` добавить регулярные выражения и обработчики административного управления меню:
     * Сокрытие/включение категорий или команд:
       `^скрой\s+(?:команды\s+)?(lms|лабы|табель|часы|почт[уа])` -> вызов `set_command_setting` и `setup_bot_commands()`, ответ: «🙈 Команды **{category}** скрыты из меню Telegram».
       `^(?:покажи|верни)\s+(?:команды\s+)?(lms|лабы|табель|часы|почт[уа])` -> вызов `set_command_setting` и `setup_bot_commands()`, ответ: «👁️ Команды **{category}** возвращены в меню Telegram».
     * Добавление кастомного алиаса:
       `^(?:называй|алиас|псевдоним)\s+/?([a-z0-9_а-яё]+)\s+(?:как|=)\s+/?([a-z0-9_а-яё]+)` -> валидация канонической команды, сохранение в `bot_custom_aliases`, подтверждение: «🏷️ Псевдоним `/{alias}` привязан к команде `/{canonical}`».
       `^удали\s+алиас\s+/?([a-z0-9_а-яё]+)` -> удаление из `bot_custom_aliases`.
   - Добавить команду `/menu` для вывода списка доступных команд с текущим статусом активности и кнопками управления.
2. Создать автотест `/opt/assistant-core/tests/test_command_aliases.py`:

   - Тест создания кастомного текстового алиаса (`/часы` -> `timesheet`) и его мгновенного срабатывания через `FastIntentRouter`.
   - Тест повторной синхронизации меню с Telegram Bot API при изменениях.
