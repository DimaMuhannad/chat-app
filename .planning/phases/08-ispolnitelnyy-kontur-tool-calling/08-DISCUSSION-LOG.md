## 1. Политика подтверждения (HITL)

| Option | Description | Selected |
|--------|-------------|:---:|
| Строгий HITL | Любое действие (календарь, напоминание, черновик) требует явного подтверждения кнопкой в Telegram перед записью | ✓ |
| Гибридная | Google Календарь требует нажатия кнопки [📅 Записать], а локальные напоминания и черновики создаются сразу | |
| Полный автопилот | Бот сразу всё записывает и сообщает об успехе, прикрепляя кнопку отмены [❌ Отменить] | |

**Выбор пользователя:** Строгий HITL для гарантированной защиты от несанкционированных или ошибочно распознанных записей.

---

## 2. Подтягивание контекста из почты («из письма Новиковой»)

| Option | Description | Selected |
|--------|-------------|:---:|
| Двухшаговый Tool Calling | Модель сама вызывает search_emails для поиска письма в SQLite, читает сниппет и формирует дату/сущности | ✓ |
| Автоподмешивание в роутере | FastIntentRouter находит последнее письмо от контакта и сразу передает его текст в промпт | |
| Явный выбор | Если есть несколько писем, бот показывает кнопки выбора конкретного письма перед созданием напоминания | |

**Выбор пользователя:** Двухшаговый Tool Calling через `search_emails`, обеспечивающий гибкость диалога и минимальное загрязнение контекста.

---

## 3. Обработка неполных дат (отсутствие конкретного времени)

| Option | Description | Selected |
|--------|-------------|:---:|
| Переспрашивать | Бот не создает событие с произвольным дефолтом, а задает короткий уточняющий вопрос: «В какое время запланировать?» | ✓ |
| Дефолт с отображением | Ставить 10:00 для календаря и 09:00 для напоминаний, явно выводя время в карточке | |
| Событие на весь день | Для календаря создавать All-day event без привязки ко времени | |

**Выбор пользователя:** Переспрашивать пользователя при отсутствии точного времени, предотвращая неверное планирование университетских и рабочих задач.

---

## 4. Обработка сбоев Google Calendar API (offline / auth)

| Option | Description | Selected |
|--------|-------------|:---:|
| Локальный буфер (Graceful Degrade) | Сохранить задачу в SQLite со статусом pending_sync и прислать кнопку [Повторить синхронизацию] | ✓ |
| Мгновенная ошибка | Сразу сообщить об ошибке подключения и предложить повторить команду позже | |
| Локальный fallback | Автоматически создать локальное напоминание вместо события Google Calendar | |

**Выбор пользователя:** Локальный буфер в SQLite со статусом `pending_sync` и интерактивной кнопкой повторной отправки.
