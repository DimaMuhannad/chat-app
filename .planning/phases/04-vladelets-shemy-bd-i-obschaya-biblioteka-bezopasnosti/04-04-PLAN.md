<threat_model>
### ASVS Level 1 Threat Assessment
- **T-04-07 (Bypass of Security Controls / Rogue Commits):** Разработчик или агент может случайно добавить токен, ключ API или файл конфигурации с секретами в индекс Git и закоммитить его в историю репозитория. *Mitigation:* Установка Git-хука `pre-commit`, который запускает `security_shield.py` перед созданием каждого коммита; при наличии любых нарушений процесс завершается с ненулевым кодом и отменяет коммит.
</threat_model>

   ```bash
   #!/usr/bin/env bash
   set -e

   REPO_ROOT="$(git rev-parse --show-toplevel)"

   # Перебор путей поиска Python гарантирует корректную работу в dev, CI и изолированных тестах tmp_path
   PYTHON_BIN=""
   for candidate in "${VIRTUAL_ENV}/bin/python" "${REPO_ROOT}/backend/.venv/bin/python" "${REPO_ROOT}/.venv/bin/python" "/opt/chat-app/backend/.venv/bin/python" "/opt/assistant-core/.venv/bin/python"; do
       if [ -n "${candidate}" ] && [ -x "${candidate}" ]; then
           PYTHON_BIN="${candidate}"
           break
       fi
   done
   if [ -z "${PYTHON_BIN}" ]; then
       PYTHON_BIN="python3"
   fi

   echo "🛡️ [Pre-Commit Hook] Запуск Security Shield проверки индексированных файлов..."
   exec "${PYTHON_BIN}" "${REPO_ROOT}/scripts/security_shield.py" "${REPO_ROOT}"
   ```
   Установить права на исполнение: `chmod +x` для обоих файлов.
2. Создать скрипты установки `scripts/install_hooks.sh` в `/opt/chat-app/scripts/install_hooks.sh` и `/opt/assistant-core/scripts/install_hooks.sh` (per D-13):
   ```bash
   #!/usr/bin/env bash
   set -euo pipefail

   REPO_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
   HOOKS_DIR="${REPO_DIR}/.githooks"
   GIT_DIR="${REPO_DIR}/.git"

   if [ ! -d "${GIT_DIR}" ]; then
       echo "Ошибка: ${REPO_DIR} не является Git-репозиторием" >&2
       exit 1
   fi

   mkdir -p "${HOOKS_DIR}"
   chmod +x "${HOOKS_DIR}/pre-commit"
   git -C "${REPO_DIR}" config core.hooksPath .githooks

   echo "✅ Pre-commit hook успешно установлен в ${REPO_DIR} (core.hooksPath = .githooks)"
   ```
   Установить права на исполнение: `chmod +x` для обоих скриптов.
3. Создать интеграционный тест `/opt/chat-app/backend/tests/test_pre_commit_hook.py` (per SEC-03, Review):

   - Настраивает `user.email` и `user.name`.
   - Копирует `.githooks/pre-commit` в `${tmp_path}/.githooks/pre-commit` и настраивает `core.hooksPath .githooks`.
   - ВАЖНО (по итогам ревью): Создаёт каталог `${tmp_path}/scripts` и копирует актуальный `/opt/chat-app/scripts/security_shield.py` в `${tmp_path}/scripts/security_shield.py` с назначением прав `chmod +x`, чтобы хук находил скрипт проверки в дереве репозитория.

   - Тест 1 (чистый коммит): создаёт файл `test.txt` с обычным текстом, индексирует (`git add test.txt`), выполняет `git commit -m "clean commit"`. Коммит успешен (код возврата 0).
