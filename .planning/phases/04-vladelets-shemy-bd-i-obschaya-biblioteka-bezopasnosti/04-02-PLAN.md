<threat_model>
### ASVS Level 1 Threat Assessment
- **T-04-03 (Denial of Service / Database Lockout):** При одновременной записи процессами `chat-app` и фонового демона дефолтный режим журнала SQLite блокирует базу целиком, приводя к сбоям `sqlite3.OperationalError: database is locked`. *Mitigation:* Обязательное включение `PRAGMA journal_mode = WAL;` (разделение читателей и писателей) и `PRAGMA busy_timeout = 5000;` (очередь ожидания блокировки до 5 секунд) при каждом создании подключения.
- **T-04-04 (Hardcoded Path Disclosure / Cross-Repository Coupling):** Наличие абсолютного хардкода `/opt/assistant-core/data/assistant.db` и вызов скрипта `src.persona.seed` из чужого виртуального окружения создаёт критическую связность и невозможность автономного развёртывания `chat-app`. *Mitigation:* Чтение пути из `SQLITE_DB_PATH` / `DATABASE_PATH` с локальным дефолтом и автономная инициализация схемы БД в тестах через `run_migrations`.
</threat_model>

   - `@asynccontextmanager async def get_async_connection(db_path: str | Path) -> AsyncGenerator[aiosqlite.Connection, None]`:
     * Вызывает `_ensure_parent_dir(db_path)`.
     * Подключается: `async with aiosqlite.connect(str(db_path), timeout=5.0) as conn:`.
     * Устанавливает: `conn.row_factory = aiosqlite.Row`.
     * Применяет PRAGMA:
       `await conn.execute("PRAGMA journal_mode = WAL;")`
       `await conn.execute("PRAGMA busy_timeout = 5000;")`
       `await conn.execute("PRAGMA foreign_keys = ON;")`
       `await conn.execute("PRAGMA synchronous = NORMAL;")`
     * Возвращает соединение через `yield conn`.
   - `@contextmanager def get_sync_connection(db_path: str | Path) -> Generator[sqlite3.Connection, None]`:
     * Вызывает `_ensure_parent_dir(db_path)`.
     * Подключается: `conn = sqlite3.connect(str(db_path), timeout=5.0)`.
     * Устанавливает: `conn.row_factory = sqlite3.Row`.
     * Применяет те же PRAGMA: WAL, busy_timeout=5000, foreign_keys=ON, synchronous=NORMAL.
     * Возвращает соединение через `yield conn` в блоке `try ... finally: conn.close()`.
