# Chat & Agent Studio (Web Analog)

Веб-платформа для интерактивного взаимодействия и разработки с автономными AI-агентами (аналог Antigravity 2.0 / Agent Chat).

## Структура проекта
- `backend/` — FastAPI WebSocket сервер оркестрации агентов.
- `frontend/` — React + Vite веб-интерфейс (Chat Canvas + Terminal + Artifacts).
- `GEMINI.md` — Инициализирующий промпт и правила разработки для автономного агента.
